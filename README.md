# VOID CLIENT

Starter project based on the official Fabric template.

## Target
- Minecraft Java 1.21.11
- Fabric Loader
- Java 21

## Current starter features
- Press **Right Shift** to open the dark ClickGUI.
- Click a module row to toggle its state.

The module entries are currently UI/state scaffolding. Features such as ESP, Fullbright,
particle control, HUD and FPS optimization still need their actual game-side implementations.

## Build
Run `./gradlew build` on a computer or a compatible online CI runner with Java 21.
The output JAR will be in `build/libs/`.

This source archive has not been compiled or tested in this environment.
